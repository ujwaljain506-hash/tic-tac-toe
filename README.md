# Tic Tac Toe with AI

A browser-based Tic Tac Toe game with an unbeatable AI opponent built using the Minimax algorithm.

## Features
- Play against an AI that never loses
- Win/draw detection
- Restart without page refresh

## Tech Stack
- HTML, CSS, JavaScript (no frameworks)

## How to Play
- Open index.html in any browser
- You play as X, AI plays as O
- Try to beat it!
